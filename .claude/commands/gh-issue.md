## Standard Workflow
1. Think through the problem, read the codebase, and write a plan to .tasks/todo.md
2. The plan should have a list of todo items with `[ ]` checkboxes
3. Before beginning work, check in with me for plan verification
4. Create a feature/ branch
5. Work through the todo items, marking them complete as you go
6. Give high-level explanations of each change
7. Keep every change as simple as possible — minimal impact
8. Add a review section to the todo.md with a summary
9. Once confident, create a pull request

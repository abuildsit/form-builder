# Analyze Issue

Fetch GitHub issue details and create a comprehensive implementation specification.

## Template Sections:

1. **Issue Summary** — Brief overview
2. **Problem Statement** — What needs solving
3. **Technical Approach** — Solution architecture
4. **Implementation Plan** — Step-by-step breakdown
5. **Test Plan** — Testing strategy and test cases
6. **Files to Modify** — Existing files that need changes
7. **Files to Create** — New files needed
8. **Existing Utilities to Leverage** — Reusable helpers
9. **Success Criteria** — Measurable completion criteria
10. **Out of Scope** — What won't be addressed

## Process:
1. Fetch issue details using `gh issue view <issue_number>`
2. Review related code and project structure
3. Analyze requirements thoroughly
4. Create detailed technical specification

# Context Prime

Prime Claude with comprehensive project understanding.

## Steps:

### 1. Architecture & Domain Context
- Read `docs/ARCHITECTURE.md` for ADRs and current state
- Understand the project domain and vocabulary

### 2. Project Guidelines
- Read root `CLAUDE.md` for overview, commands, and rules
- Read any sub-project CLAUDE.md files for specific patterns

### 3. Repository Structure
- Run: `git ls-files | head -80` for file overview
- Review source directories to understand existing structure

### 4. Configuration Review
- Review `Makefile` for available commands
- Review infrastructure config files

### 5. Key Implementation Patterns
- Read canonical route/controller patterns
- Read canonical service/model patterns
- Read permission/auth patterns

### 6. Current State Assessment
- Identify what's complete vs TODO
- Identify the next milestone

## Output:
Establish clear understanding of:
- Domain vocabulary and workflows
- Technical architecture and infrastructure
- Coding patterns and conventions
- Current state and next steps
